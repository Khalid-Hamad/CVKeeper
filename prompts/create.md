# Create a CV

Read AGENTS.md. Help me create my CV in this folder. First check for an existing
cv.md and source CVs in the included inbox/ (ignore its README.md), so we do not
start over accidentally. If I already have one, ask whether to improve it,
update specific details, or preserve its wording. Otherwise offer import or a
guided interview. Ask at most three related questions at
a time. Confirm my target role, CV language, and preferred length. I may have
projects, education, volunteering, or career changes instead of a conventional
work history. Use only confirmed facts, record unanswered questions privately,
and handle the file edits and build for me. Show me the preview and explain how
to save it as a PDF. Tell me clearly if the result is still a draft.
