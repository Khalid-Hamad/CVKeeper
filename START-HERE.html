Which app should I use?

Use an OpenAI / Codex app workflow that can open and edit a local folder, or Claude Code in the desktop app. Select the extracted CVKeeper folder, then paste the starting message. If you already use the terminal, start codex or claude from this folder.

Setup references: OpenAI app guide · Claude Code desktop guide. These links open online documentation. Accounts, pricing, and available features depend on your provider.

Do I need to install anything?

This guide and the example open in a browser without installation. Generating your own exports needs Python 3.9 or newer. Ask your assistant to check it for you. If it is missing, install Python from python.org and reopen your assistant. There are no Python packages, API keys, or servers to configure. LaTeX is optional.

I already have a CV. Can I use it?

Yes. Drop a copy into the included inbox/ folder. Ask your assistant to improve it, make a specific update, or import it with the wording unchanged. It follows AGENTS.md, preserves your original file, and asks only about missing or unclear details. A scanned PDF may need you to paste or confirm its text.

My chat app cannot open local folders.

Attach AGENTS.md, templates/cv.md, and your existing CV to the chat. Ask for the complete updated Markdown, then save it as a plain-text file named cv.md in this folder. Run python3 scripts/cv.py build from the folder (Windows: py -3 scripts/cv.py build). A folder-capable app can do these file steps for you.

How do I update or tailor it later?

Open the same folder in your assistant and describe the change. Ask it to follow AGENTS.md. It should back up your previous CV and rebuild the preview. For a specific job, ask for a tailored copy while keeping your master CV unchanged. Ready-to-use messages are in prompts/.

What are the PDF settings and filename?

Open your generated output/cv.html, choose Save as PDF, use A4 paper and 100% scale, and turn off browser headers and footers. If you need US Letter, ask your assistant to rebuild for Letter first. Save with the exact name displayed above the CV: FirstName_LastName_YYYY-MM-DD_buildNumber.pdf. The page title suggests this name, but confirm it in your browser's save dialog.

The date is the local build date. Each build increases the number in that output folder and keeps the earlier numbered exports. Tell your assistant your preferred first and family names if either has more than one word. Review all pages, check links, and make sure text can be selected. A saved PDF will not update automatically after future changes.

Where is my information stored?

Your master is cv.md; generated files live in output/. Local scripts make no network requests. Your AI app handles the information you share under its own policies. Keep a private backup of the whole working folder. Git ignores personal working files by default, but that does not encrypt them or protect a folder you share manually.
