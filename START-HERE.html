How do I use this in Claude Desktop?

Use Claude Desktop's Cowork area and connect this extracted folder, or use its Code workflow when available. Paste the short starting message. Use a folder-capable session rather than a normal chat that only receives attachments, because CVKeeper saves your career profile and review state for future updates.

Official references: Claude Cowork · Cowork projects · file creation. Accounts and available features may vary.

Do I need to install anything?

This guide and the example open in a browser without installation. Generating your own exports needs Python 3.9 or newer. Ask your assistant to check it for you. If it is missing, install Python from python.org and reopen your assistant. There are no Python packages, API keys, or servers to configure. LaTeX is optional.

I already have a CV. Can I use it?

Yes. Drop a copy into the included inbox/ folder. Ask your assistant to improve it, make a specific update, or import it with the wording unchanged. It follows AGENTS.md, preserves your original file, and asks only about missing or unclear details. A scanned PDF may need you to paste or confirm its text.

My chat app cannot open local folders.

Attach AGENTS.md, templates/cv.md, and your existing CV to the chat. Ask for the complete updated Markdown, then save it as a plain-text file named cv.md in this folder. Run python3 scripts/cv.py build from the folder (Windows: py -3 scripts/cv.py build). A folder-capable app can do these file steps for you.

How do I update or tailor it later?

Open the same folder in your assistant and describe the change. Ask it to follow AGENTS.md. It should back up your previous CV and rebuild the preview. For a specific job, ask for a tailored copy while keeping your master CV unchanged. Ready-to-use messages are in prompts/.

Why did Windows save a webpage?

An HTML preview is a webpage. Ctrl+S saves it as HTML. Ask the assistant to deliver the actual PDF. If you must export manually, open the preview and press Ctrl+P, choose Save as PDF in Chrome or Microsoft Print to PDF in Edge, then save. Use A4 and turn off print headers and footers.

The PDF filename follows FirstName_LastName_YYYY-MM-DD_buildNumber.pdf automatically. You do not need to discuss it in the starting prompt.

Where is my information stored?

Your master is cv.md. Your career facts, field-specific writing guide, unresolved questions, and review state live privately under notes/. Generated files live in output/. Local scripts make no network requests. Your AI app handles information under its own policies. Keep a private backup of the whole working folder. Git ignores personal files by default, but that is not encryption.
