# Project provenance

CVKeeper was developed from Khalid Hamad AlSubaie's
[MyResumeTemp](https://github.com/Khalid-Hamad/MyResumeTemp), an MIT-licensed,
section-based LaTeX resume repository. The original layout included a credit
to Audric Serador and inspiration from [sb2nov/resume](https://github.com/sb2nov/resume).

This starter replaces the original personal CV content with a blank template
and a fictional example. Its optional LaTeX template adapts the original
article-based structure, sans-serif typography, section rules, and compact
lists. The standard workflow now uses Markdown and printable HTML.

The original MIT license is retained in `LICENSE`. Names, dates, employers,
and qualifications in `examples/` are fictional and provided only to show
formatting. They must not be represented as the user's qualifications.
